# Newe Taikwanna

**Speaking Shoshoni**

*Oyon newenee pa'anten–himpaisen, uttuse, ekittsi, wa'ai kaisen nahate.*
*To all Shoshone–past, present, and future.*

This repository is an [Obsidian](https://obsidian.md) vault for *Newe Taikwanna*, a book-in-progress introducing the Western dialect of the Shoshoni language.

## Using the vault

Clone the repository and open the folder as a vault in Obsidian. Start at `Home.md`.

| Folder | Contents |
| --- | --- |
| `Front Matter/` | Dedication, acknowledgements, preface, abbreviations |
| `Part 1 - Introduction/` | The Shoshoni language, the Shoshone people, and the Shoshone homelands |
| `Part 2 - Lessons/` | Lessons on speaking Shoshoni |
| `Part 3 - Reference/` | Glossary of grammatical terms, Shoshoni-English and English-Shoshoni dictionaries, index |
| `Attachments/` | Images |

Each Shoshoni word has its own note in `Part 3 - Reference/Dictionary/Shoshoni/`, so words used in the text link straight to their dictionary entries.
